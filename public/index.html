CSV format

One row per person. Header row required. Column order does not matter.

nameFull name. First name is used for {{first_name}}.
phoneAny format — 937-555-0142, (937) 555-0142, +19375550142.
groupBroadcast list name. One group per row; repeat the person to put them in two groups.
consentRequired. Must be yes to receive anything. Anything else is skipped.
notesOptional, staff-facing only. Never sent.
